# Statsig Connector — Preparation

**Category:** C41. Feature Flags & Progressive Delivery  
**Vendor URL:** https://statsig.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Statsig** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C41. Feature Flags & Progressive Delivery**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **Growth-инженер** сталкивается с задачей: **управление Feature Gates, динамическими конфигурациями и A/B-экспериментами с автоматической оценкой метрик**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Statsig переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **Growth-инженер, Data Scientist, продакт-менеджер**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `проверка состояния Feature Gate -> включение гейта для тестовой когорты -> мониторинг влияния на метрики`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Statsig.
